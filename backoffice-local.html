📘 MODE D'EMPLOI

Ajouter un véhicule : Remplissez le formulaire à droite (Marque, Modèle et Prix sont obligatoires). Ajoutez des photos et cliquez "Ajouter".

Marquer comme vendu : Cliquez le bouton vert "Vendu ✓" sur le véhicule. Il restera visible sur le site pendant 7 jours avec un bandeau VENDU bien visible, puis sera automatiquement retiré.

Publier sur le site : Cliquez "📤 Exporter pour le site" pour télécharger le fichier vehicles.json. Placez ce fichier dans le dossier data/ de votre site (en remplaçant l'ancien).

Sauvegarder : "💾 Sauvegarde complète" exporte tout (y compris les véhicules vendus) pour pouvoir restaurer plus tard via "📥 Importer".

⚠️ Important : Les données sont stockées dans votre navigateur. Si vous changez de navigateur ou videz le cache, utilisez la sauvegarde complète pour ne rien perdre.
